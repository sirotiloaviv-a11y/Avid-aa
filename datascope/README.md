# DataScope — כלי לימודי לניתוח נתונים היסטוריים

DataScope מייבא קובץ CSV של נתוני מחירים היסטוריים, בודק אותו בקפדנות, מציג גרפים וטבלה,
ומסביר בעברית את הסטטיסטיקה התיאורית שחושבה. הכול רץ בדפדפן, ללא שרת, ללא בסיס נתונים,
ללא חשבון, ללא מפתח API וללא שום תלות שצריך להתקין.

**מה הכלי אינו עושה, במכוון:** אין בו נתוני שוק בזמן אמת, אין בו איתותי מסחר, אין בו המלצות
קנייה או מכירה, אין בו דירוג הזדמנויות, אין בו תחזיות מחיר, אין בו חיבור לברוקר, אין בו ביצוע
פקודות ואין בו סימולציית מסחר. זהו כלי לימודי לניתוח נתונים שהמשתמש מספק.

## מה הכלי עושה

* **ייבוא** קובץ CSV בבחירה מהמחשב או בגרירה, עד 5 מ״ב ועד 50,000 שורות נתונים.
* **ולידציה** של כותרות, תאים חסרים, תאריכים, מספרים, כפילויות ומגבלות גודל — עם דוח שגיאות
  מפורט הכולל מספרי שורות.
* **בחירת סמל** מתוך הסמלים שנמצאו בפועל בקובץ, עם חיפוש.
* **סינון לפי טווח תאריכים**, שמסנכרן את כל הרכיבים בבת אחת.
* **סטטיסטיקה תיאורית**: מספר תצפיות, תאריכי ומחירי התצפית הראשונה והאחרונה, שינוי באחוזים,
  סגירה נמוכה וגבוהה, ומחזור ממוצע — כל אחד עם הסבר קצר בעברית.
* **שני גרפים נפרדים**: מחיר סגירה ומחזור, עם סמן מקלדת, הקראה נגישה ו־tooltip.
* **טבלת נתונים** הניתנת למיון ולדפדוף.
* **סיכום אוטומטי** בעברית, שנוצר מתבניות טקסט מקומיות.
* **ייצוא** של הנתונים המסוננים ל־CSV ושל דוח מסכם ל־TXT.
* **ניקוי נתונים** בלחיצה אחת.

## דרישות מוקדמות

* **Node.js 20 ומעלה** — רק כדי להריץ שרת קבצים סטטי מקומי ואת הבדיקות. הכלי עצמו אינו מריץ
  קוד בצד שרת.
* **דפדפן מודרני** שתומך ב־ES Modules: Chrome/Edge 91+, Firefox 90+, Safari 15+.
* **אין תלויות npm.** אין צורך ב־`npm install`, ואין `node_modules`.

בדיקת הגרסה:

```bash
node --version    # v20.0.0 ומעלה
```

## התקנה והרצה

```bash
git clone https://github.com/sirotiloaviv-a11y/avid-aa.git
cd avid-aa/datascope
npm start
```

`npm start` מדפיס:

```
DataScope מוגש מתוך: /.../avid-aa/datascope
נא לפתוח בדפדפן: http://127.0.0.1:4173/
לעצירה: Ctrl+C
```

יש לפתוח בדפדפן את **<http://127.0.0.1:4173/>**.

לבחירת פורט אחר:

```bash
npm start -- --port 8080
```

אפשר גם להשתמש בכל שרת קבצים סטטי אחר, למשל:

```bash
python3 -m http.server 4173      # מתוך תיקיית datascope
```

> **חשוב:** יש לפתוח את הכלי דרך `http://` ולא בלחיצה כפולה על `index.html`. הדפדפן חוסם טעינת
> מודולי ES מכתובת `file://` מטעמי אבטחה (CORS), והדף ייראה ריק. ראו [פתרון תקלות](#פתרון-תקלות).

## שימוש ראשון

1. לוחצים **«טעינת דוגמה»** — נטענים נתוני הדגמה מומצאים לשלושה סמלים.
2. בוחרים סמל ברשימה **«סמל נבחר»** (אפשר לסנן בשדה החיפוש).
3. מצמצמים את הטווח בשדות **«מתאריך»** ו**«עד תאריך»**. כל הגרפים, הסטטיסטיקה, הטבלה והסיכום
   מתעדכנים יחד.
4. קוראים את הסטטיסטיקה. מתחת לכל מדד מופיע הסבר קצר מה הוא אומר ומה הוא לא אומר.
5. מורידים **«דוח בעברית (TXT)»** או **«הנתונים המסוננים (CSV)»**.
6. לוחצים **«ניקוי נתונים»** כדי למחוק הכול מהמסך ומהזיכרון.

ניווט במקלדת: Tab לרכיב הבא, חצים ימינה/שמאלה להזזת הסמן בגרף, Home ו־End לקצוות,
Escape להסרת הסמן. הערך שנקרא מוצג בשורת ההקראה מתחת לגרפים.

## תבנית ה־CSV

שורת כותרות ואחריה שורות נתונים. עמודות החובה:

```
date,symbol,close,volume
2024-01-02,DEMO_A,100.42,1357404
2024-01-03,DEMO_A,100.68,822569
2024-01-02,DEMO_B,42.14,431890
```

| עמודה | דרישה |
|---|---|
| `date` | תאריך קיים בתבנית `YYYY-MM-DD`. תאריך כמו `2024-02-30` נדחה. |
| `symbol` | מזהה שאינו ריק, עד 64 תווים. |
| `close` | מספר סופי וחיובי. ללא פסיקים, רווחים או סימני מטבע. |
| `volume` | מספר סופי שאינו שלילי. אפס מותר. |

כללים נוספים:

* קידוד **UTF-8**, עם או בלי BOM.
* שדות במירכאות נתמכים, כולל פסיקים, מירכאות כפולות (`""`) ושורות חדשות בתוך שדה.
* סדר העמודות אינו חשוב, והשוואת הכותרות אינה תלוית רישיות.
* עמודות נוספות (למשל `open`, `high`) מותרות והכלי מתעלם מהן.
* כל צמד `symbol` + `date` יכול להופיע פעם אחת בלבד.
* מגבלות: **5 מ״ב** ו**50,000 שורות נתונים**.

**שורה שגויה אחת חוסמת את כל הייבוא.** זו החלטה מכוונת: הכלי לא מדלג על שורות ולא ממציא ערכים
חסרים, כי סטטיסטיקה שחושבה על נתונים ש«תוקנו» בשקט נראית בדיוק כמו סטטיסטיקה נכונה.
דוח השגיאות מציין את מספר השורה, את שם העמודה ואת הערך שנמצא.

**תאריכים חסרים אינם שגיאה.** סופי שבוע, חגים וימים שאין עליהם רשומה פשוט אינם מופיעים, והכלי
אינו משלים אותם ואינו מעריך ערכים במקומם.

אם השורות בקובץ אינן בסדר כרונולוגי, הכלי ממיין אותן לצורך התצוגה והחישוב ומציג על כך הודעה.
הקובץ המקורי אינו משתנה.

## נתוני ההדגמה

הכלי כולל נתונים סינתטיים דטרמיניסטיים לשלושה סמלים: **DEMO_A**, **DEMO_B** ו־**DEMO_C**,
על פני 252 ימי מסחר בשנת 2024 (ימי חול, בלי סופי שבוע ובלי רשימת ימים סגורים קבועה).

> **אלה נתונים מומצאים.** הם נוצרים במחולל מקומי עם זרע קבוע (`src/lib/demo.js`), אינם מתייחסים
> לחברה, לנייר ערך או לשוק אמיתיים, ואינם מבוססים על שום מקור נתונים — לא חיצוני ולא זיכרון של
> מודל כלשהו. הם קיימים כדי להדגים את הממשק.

שתי דרכים לקבל אותם:

* **«טעינת דוגמה»** — טוען אותם ישירות לכלי (דרך אותו מסלול ולידציה בדיוק כמו קובץ אמיתי).
* **«הורדת CSV לדוגמה»** — מוריד את אותם נתונים כקובץ, כדי לבחון את מסלול הייבוא מקובץ.

עותק של הקובץ נמצא גם ב־[`sample/datascope_sample.csv`](sample/datascope_sample.csv).
ליצירתו מחדש: `npm run sample`.

כל מסלול ההדגמה עובד ללא חשבון, ללא מפתח API וללא ספק נתונים חיצוני.

## ייצוא

| כפתור | תוכן | שם הקובץ |
|---|---|---|
| הורדת הנתונים המסוננים (CSV) | רק השורות של הסמל והטווח שנבחרו | `datascope_<סמל>_<תאריך>.csv` |
| הורדת דוח בעברית (TXT) | התקופה, הסטטיסטיקה, הסיכום האוטומטי והמגבלות | `datascope_<סמל>_<תאריך>.txt` |

שם הקובץ נבנה מהסמל ומתאריך הייצוא, אחרי שהסמל צומצם לתווים בטוחים בלבד.

ב־CSV המיוצא, כל תא שמתחיל ב־`=`, `+`, `-`, `@`, טאב או CR מקבל גרש מוביל, כדי שגיליון
אלקטרוני לא יפרש תוכן שהגיע מקובץ חיצוני כנוסחה.

## הרצת הבדיקות והבנייה

```bash
npm test          # בדיקות יחידה ואינטגרציה (node:test) — ללא תלויות
npm run build     # בדיקת מודולים, ביקורת קוד ואריזה לתיקיית dist/
npm run preview   # הגשת dist/ שנבנה
npm run test:e2e  # בדיקת דפדפן מלאה (דורשת Playwright; מדלגת אם אינו מותקן)
```

`npm test` מכסה: ייבוא תקין, כותרות חסרות, תאריכים לא חוקיים, ערכים מספריים לא חוקיים,
כפילויות `symbol`+`date`, מגבלות גודל ושורות, מיון כרונולוגי, בחירת סמל וסינון תאריכים,
שינויים באחוזים ידועים (כולל 100 → 110 = 10%), בחירה ריקה ובחירה של תצפית אחת, טיפול בטוח
בטקסט מיובא ובייצוא, והתאמה בין הנתונים המסוננים לסטטיסטיקה המוצגת.

`npm run build` מוודא שכל מודול נטען, מריץ ביקורת מקור (ללא הפניות חיצוניות, ללא גישה לרשת,
ללא שמירה מתמשכת, ללא `innerHTML`, ללא `eval`), ממזער את גיליון הסגנונות וכותב `dist/`
יחד עם `dist/build-info.json`.

`npm run test:e2e` מריץ את מסלול ההדגמה המלא בדפדפן אמיתי ומשווה את המספרים שמוצגים על המסך
לחישוב עצמאי מאותם מודולים.

## פרטיות ואבטחה

* **הקובץ נקרא בדפדפן בלבד.** תוכנו אינו נשלח לשום שרת. אין בכלי קריאות רשת כלל.
* **אין מדידות, אין טלמטריה ואין משאבים חיצוניים.** אין גופנים מרוחקים, אין CDN, אין סקריפטים
  של צד שלישי. כל מה שהדף טוען נמצא בתיקייה הזו.
* **אין שמירה בין ביקורים.** הכלי אינו משתמש ב־localStorage, ב־sessionStorage, ב־IndexedDB או
  בעוגיות. רענון הדף מאפס הכול.
* **תוכן ה־CSV נחשב קלט לא מהימן.** טקסט מיובא מוצג תמיד כטקסט (`textContent`) ולעולם לא כ־HTML.
* **הגנה מפני הזרקת נוסחאות** בייצוא CSV, ושמות קבצים מצומצמים לתווים בטוחים.
* **אין סודות בקוד.** אין מפתחות, אין אסימונים ואין כתובות של שירותים.

הכללים האלה נאכפים מכנית: `scripts/audit.mjs` רץ גם בבנייה וגם כבדיקה, ונכשל אם מודול שנשלח
לדפדפן מפר אחד מהם.

## מגבלות ידועות

* **התאמה לפיצולים ולדיבידנדים:** התוצאות תלויות בשאלה אם המחירים בקובץ כבר מתואמים. הכלי אינו
  מבצע התאמות ואינו יכול לזהות אם בוצעו.
* **מטבע:** הקובץ אינו מציין מטבע, ואין הנחה שכל הסמלים נקובים באותו מטבע. המחירים מוצגים כמספרים
  בלבד, ואין להשוות מחירים בין סמלים ללא מידע נוסף.
* **סיבתיות:** הכלי אינו מסיק מדוע מחיר זז. מחירים לבדם אינם מכילים את הסיבה.
* **השינוי באחוזים** משווה בין שתי תצפיות — הראשונה והאחרונה בטווח — ואינו מתאר את הדרך ביניהן.
  הוא אינו תשואה כוללת ואינו מביא בחשבון דיבידנדים, פיצולים או עמלות.
* **המחזור הממוצע** הוא ממוצע חשבוני על התצפיות הקיימות בלבד. ימים חסרים אינם נספרים.
* **הציר האופקי בגרפים** מציג תצפיות ברווחים שווים ולא לפי לוח השנה, ולכן פער של שבוע נראה כמו
  פער של יום.
* **דיוק מספרי:** החישובים משתמשים במספרים עשרוניים של JavaScript (IEEE‑754). הנוסחה
  `100 × (סגירה אחרונה / סגירה ראשונה − 1)` מחושבת בלי עיגול ביניים, ולכן 100 → 110 מתקבל
  כ־10.000000000000009 ומוצג כ־`+10.00%`. העיגול נעשה רק בתצוגה.
* **גודל:** עד 5 מ״ב ועד 50,000 שורות. קובץ גדול יותר צריך פיצול.
* **אורך סמל:** עד 64 תווים.
* **הסיכום האוטומטי** מבוסס תבניות טקסט בלבד. אין מאחוריו מודל בינה מלאכותית.
* **אין מצב לא־מקוון מותקן (PWA)** ואין שמירת העדפות.

## פתרון תקלות

| תופעה | סיבה ופתרון |
|---|---|
| הדף נפתח ריק, ובקונסול מופיע `CORS policy` או `Failed to load module` | פתחתם את `index.html` ישירות מהדיסק. יש להריץ `npm start` ולגשת ל־`http://127.0.0.1:4173/`. |
| `Error: listen EADDRINUSE` | הפורט תפוס. `npm start -- --port 8080`. |
| `npm start` נכשל עם שגיאת תחביר | גרסת Node ישנה מדי. נדרשת 20 ומעלה: `node --version`. |
| «הייבוא נחסם» עם «חסרה עמודת חובה» | שורת הכותרות אינה מכילה את כל ארבע העמודות. יש לוודא `date,symbol,close,volume` בשורה הראשונה. |
| «מספר התאים בשורה אינו תואם למספר הכותרות» | יש פסיק בתוך שדה בלי מירכאות. יש לעטוף את הערך במירכאות: `"Smith, John"`. |
| «מחיר סגירה חייב להיות מספר סופי וחיובי» | בקובץ יש פסיקים כמפריד אלפים, סימן מטבע או רווח. יש להסיר אותם. |
| «כפילות: הצמד סמל+תאריך» | אותה תצפית מופיעה פעמיים. יש להשאיר שורה אחת לכל סמל ותאריך. |
| תווים משובשים במקום עברית או סמלים | הקובץ אינו UTF-8. יש לשמור אותו מחדש כ־UTF-8 (עם או בלי BOM). |
| «אין תצפיות בטווח שנבחר» | הטווח אינו מכיל רשומות. אפשר ללחוץ «איפוס טווח התאריכים». זו אינה שגיאה. |
| הקובץ המיוצא נפתח מעוות ב־Excel | יש לפתוח דרך Data → From Text/CSV ולבחור UTF-8. הכלי כותב BOM כדי לסייע בזיהוי. |
| `npm run test:e2e` מדלג | Playwright אינו מותקן. זו בדיקה אופציונלית; `npm test` היא הבדיקה העיקרית. |
