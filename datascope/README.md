# DataScope — מעקב שוק בזמן אמת

לוח מחוונים מקומי למעקב אחר **מניות אמריקאיות** ו**מטבעות קריפטו** בזמן אמת: כרטיסי מחיר
מתעדכנים, **גרף נרות** וגרף מחזור חיים, סרגל נעים של מובילי תנועה, ומנוע התראות ששולח
**התראות דפדפן** גם כשהלשונית ברקע — בעיצוב כהה עם משטחי זכוכית והדגשי ניאון.

הכול רץ בדפדפן שלך מול שרת קבצים מקומי. אין שרת אחורי, אין בסיס נתונים, ואין צורך בהתקנת
חבילות npm.

## דרישות מוקדמות

* **Node.js 20 ומעלה** — משמש רק כדי להגיש את הקבצים ולהפעיל את ה־proxy למניות.
* **דפדפן מודרני** עם תמיכה ב־ES Modules וב־WebSocket: Chrome/Edge 91+, Firefox 90+, Safari 15+.
* **אין תלויות npm.** אין צורך ב־`npm install` ואין `node_modules`.
* חיבור לאינטרנט — לספקי הנתונים בלבד.

```bash
node --version    # v20.0.0 ומעלה
```

## הפעלה מהירה

```bash
git clone https://github.com/sirotiloaviv-a11y/avid-aa.git
cd avid-aa/datascope
npm start
```

הפקודה מדפיסה:

```
DataScope מוגש מתוך: /.../avid-aa/datascope
נא לפתוח בדפדפן: http://127.0.0.1:4173/
proxy למניות (Yahoo) פעיל בנתיב /api/yahoo
לעצירה: Ctrl+C
```

יש לפתוח בדפדפן את **<http://127.0.0.1:4173/>**.

מיד עם הפתיחה:

* הקריפטו מתחבר ל־Binance ב־WebSocket ומתחיל לזרום (בלי מפתח, בלי הרשמה),
* המניות נמשכות דרך ה־proxy המקומי מ־Yahoo Finance כל 15 שניות,
* רשימת המעקב ההתחלתית היא BTC, ETH, SOL, AAPL, MSFT, NVDA.

לפורט אחר:

```bash
npm start -- --port 8080
```

> **חשוב:** יש לפתוח דרך `http://127.0.0.1` ולא בלחיצה כפולה על `index.html`. הדפדפן חוסם
> טעינת מודולי ES מכתובת `file://`, וגם התראות הדפדפן דורשות הקשר מאובטח (`127.0.0.1` נחשב
> מאובטח).

## מקורות הנתונים

| נכסים | ספק | מפתח | קצב | עיכוב |
|---|---|---|---|---|
| קריפטו | Binance — זרם WebSocket ציבורי | לא נדרש | זמן אמת, מספר הודעות בשנייה | אין |
| מניות (ברירת מחדל) | Yahoo Finance דרך ה־proxy המקומי | לא נדרש | סקר כל 15 שניות | ייתכן עיכוב |
| מניות (מומלץ) | Finnhub — זרם WebSocket | מפתח חינמי | זמן אמת, לפי עסקה | אין |
| שמות מטבעות | CoinGecko | לא נדרש | פעם אחת בטעינה | — |

כל נכס מציג את שעת העדכון האחרון שלו, ומקור שאינו מתחייב לזמן אמת מסומן **«ייתכן עיכוב»**.

### חיבור Finnhub לזמן אמת במניות (אופציונלי)

1. להירשם בחינם ב־<https://finnhub.io> ולהעתיק את המפתח מלוח הבקרה.
2. בדף: **הגדרות** ← להדביק בשדה **מפתח Finnhub** ← **שמירה והתחברות מחדש**.
3. הפס של «מניות» יעבור ל«מחובר», והמחירים יגיעו בזרם במקום בסקר.

המפתח נשמר ב־localStorage של הדפדפן ונשלח אך ורק אל `finnhub.io`. למחיקה: **הגדרות** ←
**מחיקת המפתח**.

### אם Binance חסום באזור שלך

Binance מסרב לחיבורים מכמה מדינות. אפשר להצביע על נקודת קצה חלופית דרך פרמטרים בכתובת:

```
http://127.0.0.1:4173/?binanceWs=wss://stream.binance.us:9443&binanceRest=https://api.binance.us
```

מותרות רק כתובות מרשימת היתר קבועה (`src/lib/config.js`), כדי שקישור זדוני לא יוכל להפנות את
הלוח לשרת שמזין אותו במחירים מומצאים.

## הגדרת התראות

ההתראות מוגדרות בלוח **«מנוע התראות»** שבתחתית הדף:

1. **נכס** — כל נכס שנמצא ברשימת המעקב.
2. **סוג התראה** — אחד משלושה:

   | סוג | מתי מופעלת | דוגמה |
   |---|---|---|
   | **מחיר יעד** | המחיר חוצה סף למעלה או למטה | «BTC עולה אל 70,000 או מעל» |
   | **זינוק באחוזים** | שינוי של X% בתוך חלון זמן, או מאז פתיחת היום | «AAPL עולה 3% מאז פתיחת היום» |
   | **זינוק במחזור** | המחזור בחלון גבוה פי X מהממוצע ההיסטורי | «SOL במחזור פי 3 מהרגיל ב־5 דקות» |

3. **ערכי הסף** — מחיר יעד, אחוז, או כפולה מהממוצע.
4. **חלון זמן** — לזינוקי אחוזים ומחזור: דקה / 5 דקות / 15 דקות / שעה.
5. **זמן צינון** — כמה זמן להשתיק את אותה התראה אחרי שהופעלה (ברירת מחדל: 5 דקות).
6. לחיצה על **הוספת התראה**.

### איך מנוע ההתראות מחליט להפעיל

התראה נשלחת ב**רגע המעבר** מ«לא מתקיים» ל«מתקיים» — לא בכל טיק שבו התנאי עדיין נכון. אחרי
הפעלה הכלל «נועל» את עצמו, ומשתחרר רק כשהתנאי מפסיק להתקיים. בנוסף, זמן הצינון מונע הפעלה
חוזרת כשהמחיר מרצד סביב הסף. בלי שני המנגנונים האלה התראה אחת הייתה הופכת למאות התראות,
ואז מכבים אותן — והתראה מושתקת שווה לאין התראה.

כלל שאינו יכול להתעדכן מסביר זאת בשורה שלו, למשל «אין מספיק היסטוריה לחלון הזמן שנבחר» —
כלל שיושב בשקט בלי סיבה נראית לעין הוא בדיוק מה שגורם לאבד אמון בכלי.

**היסטוריית התראות** מציגה כל הפעלה עם שעה, שם הנכס המלא, הסמל, הכלל והמחיר בעת ההפעלה.
אפשר לייצא אותה ל־CSV.

## התראות דפדפן וצליל

1. ללחוץ **«הפעלת התראות בדפדפן»** בראש הדף.
2. לאשר את בקשת ההרשאה של הדפדפן.

מרגע זה:

* התראה מופיעה **גם כשהלשונית ברקע או ממוזערת**,
* כותרת ההתראה כוללת את **שם הנכס המלא והסמל** יחד — למשל `Apple Inc. / AAPL` או
  `Bitcoin / BTC/USDT`,
* גוף ההתראה מפרט מה קרה, באיזה מחיר ובאיזו שעה,
* מתנגן **צליל קצר** שנוצר מקומית (Web Audio), מפני שהצליל של התראות המערכת אינו עקבי בין
  מערכות הפעלה. לכיבוי: כפתור **«צליל פעיל»**.

אם ההרשאה נחסמה, הדף אומר זאת במפורש וההתראות ימשיכו להופיע בתוך הדף ובהיסטוריה.

> הדפדפן חייב להישאר פתוח. אין כאן Service Worker ואין שרת — סגירת הדפדפן עוצרת את המעקב.

## העיצוב

ערכת נושא **כהה בלבד**, בנויה סביב רקע כחול־שחור עמוק, משטחי זכוכית והדגשי ניאון.

מעל הגרף יש שתי לשוניות: **נרות** (ברירת המחדל) ו**קו**. הבחירה נשמרת בדפדפן וחוזרת בטעינה
הבאה, וניווט ביניהן אפשרי גם בחצים.

| תפקיד | ערך |
|---|---|
| רקע ראשי | `#0b0f17` |
| עלייה | `#10b981` (אמרלד) |
| ירידה | `#ef4444` (אדום) |
| התראות ומיקוד | `#6366f1` (אינדיגו) |
| אזהרה / עיכוב | `#f59e0b` (ענבר) |

* **משטחי זכוכית:** רקע שקוף־למחצה עם `backdrop-filter`, מסגרת דקה, קו אור עליון וצל רך.
* **תגים זוהרים:** נקודת החיבור פועמת כל עוד הזרם חי ונעצרת כשהוא נופל, כך שתנועה תמיד אומרת
  שנתונים זורמים. התראה חדשה נכנסת להיסטוריה עם הבזק אינדיגו, ומחיר שזז מהבהב בכיוון שלו.
* **גרף נרות:** נרות עלייה **מלאים** ונרות ירידה **חלולים**. זו אינה קישוטיות — אמרלד ואדום
  יושבים בדיוק על סף ההפרדה לעיוורון צבעים (ΔE 8.1 בדויטרנופיה), ולכן לכיוון יש ערוץ שני שאינו
  תלוי בגוון. גם כל אחוז שינוי בממשק נושא חץ ומילה, לא רק צבע.
* **RTL:** כל ההיסעים בגיליון הסגנונות הם לוגיים (`inset-inline`, `padding-inline`), כך שהפריסה
  מתהפכת נכון. שני הגרפים בלבד חוזרים ל־LTR, מפני שציר זמן רץ משמאל לימין בכל שפה. מספרים,
  מחירים וסמלים עטופים ב־`.num` עם בידוד דו־כיווני, כדי ש־«BTC/USDT» לא יסדר מחדש את העברית
  סביבו.
* **תנועה:** ההנפשות הן קישוט בלבד — כל ערך שהן נושאות כתוב גם כטקסט. `prefers-reduced-motion`
  מכבה את כולן, כולל הסרגל הנע.

### מה לא מומש, ולמה

התבקשו Tailwind CSS, Shadcn/ui (Radix), Lucide React ו־Recharts או Lightweight-Charts. הסביבה
שבה נכתב הקוד חוסמת את מרשם ה־npm, והפרויקט אינו React ואין בו באנדלר — כך ששלוש מהחבילות
האלה היו גוררות גם את React וגם כלי בנייה. במקומן:

| התבקש | מה יש בפועל |
|---|---|
| Tailwind CSS | שכבת טוקנים ב־CSS עם אותם שמות וערכים (`--emerald-500`, `--indigo-500`) — מיפוי ישיר אם תרצו להעביר ל־Tailwind |
| Shadcn/ui (Radix) | אותו אוצר רכיבים בוונילה: Card, Badge, Tabs, Switch, Table ו־Dialog. הדיאלוג הוא `<dialog>` מקורי, שמספק מלכודת פוקוס, Escape ורקע לא־פעיל |
| Lucide React | `src/ui/icons.js` — אייקונים מצוירים ידנית באותה שפה חזותית (24×24, קו 2px, `currentColor`). אינם Lucide ואינם מתחזים לו |
| Recharts / Lightweight-Charts | מנוע SVG עצמאי עם נרות, קו זוהר, שכבת שטח, צלב־מיקוד וניווט מקלדת |

כל אלה שקולים חזותית ותפקודית, אבל אינם אותן הספריות שהתבקשו. מעבר לסטאק המקורי דורש
`npm install` בסביבה עם גישה למרשם, ולאחר מכן כתיבה מחדש של שכבת ה־UI כרכיבי React.

## הרצה ללא אינטרנט (שרת דמה)

הפרויקט כולל שרת שוק מקומי שמדבר בדיוק באותם פורמטים כמו הספקים האמיתיים. זה מאפשר להדגים
את הלוח, לבדוק התראות ולראות אותן נורות — בלי חיבור לאינטרנט ובלי להמתין לשוק.

בטרמינל אחד:

```bash
npm run mock          # מאזין ב־http://127.0.0.1:4500
```

בטרמינל שני:

```bash
npm start
```

ואז לפתוח את הכתובת הזו (שורה אחת):

```
http://127.0.0.1:4173/?binanceWs=ws://127.0.0.1:4500/binance&binanceRest=http://127.0.0.1:4500/binance&yahooRest=http://127.0.0.1:4500/yahoo&coingeckoRest=http://127.0.0.1:4500/coingecko
```

להנעת המחירים ידנית:

```bash
# קביעת מחיר מדויק — הדרך הפשוטה לראות התראת «מחיר יעד» נורית
curl -X POST http://127.0.0.1:4500/control/price \
  -H 'content-type: application/json' -d '{"symbol":"BTCUSDT","price":70000}'

# קפיצה באחוזים
curl -X POST http://127.0.0.1:4500/control/spike \
  -H 'content-type: application/json' -d '{"symbol":"SOLUSDT","percent":8}'

# פרץ מחזור
curl -X POST http://127.0.0.1:4500/control/volume \
  -H 'content-type: application/json' -d '{"symbol":"ETHUSDT","multiple":8}'

# המצב הנוכחי
curl http://127.0.0.1:4500/control/state
```

## בדיקות ובנייה

```bash
npm test          # 96 בדיקות יחידה ואינטגרציה (node:test) — ללא תלויות
npm run build     # בדיקת מודולים, ביקורת מקור ואריזה ל־dist/
npm run preview   # הגשת dist/ שנבנה
npm run test:e2e  # 25 בדיקות דפדפן מלאות מול שרת הדמה (דורש Playwright)
```

`npm test` מכסה:

* **פענוח נתונים חיים** — מטענים בפורמט המדויק של Binance (שדות מספריים כמחרוזות, מסגרות
  combined-stream, נרות), Finnhub (חותמות בשניות, מסגרות עסקאות מקובצות), Yahoo (מערכי נרות
  עם חורי `null`) ו־CoinGecko.
* **מנוע ההתראות** — כל שלושת סוגי הכללים, הפעלה על מעבר סף, אי־הפעלה חוזרת, שחרור נעילה,
  זמן צינון, מחיר מרצד, חוסר היסטוריה, וחלוקה באפס.
* **הסדרה מתגלגלת** — קיבוץ עסקאות לנרות, חסם זיכרון, הודעות מחוץ לסדר.
* **חיבורים** — התחברות מחדש, השהיה מצטברת (backoff), זיהוי ערוץ שקט, ורשימת ההיתר לכתובות.
* **אבטחה** — ביקורת מקור, הגנת נוסחאות בייצוא, ושמות קבצים בטוחים.

`npm run test:e2e` מריץ את הלוח בדפדפן אמיתי מול שרת הדמה: חיבור, זרימת מחירים, גרף נרות
(כולל מלא מול חלול), מעבר ללשונית «קו» ושמירת הבחירה, החלפת נכס, חיפוש, הפעלת התראה ובדיקת
**הטקסט המדויק של ההתראה**, היסטוריה, שמירה אחרי רענון, ייצוא, ניתוק ושחזור, ותצוגת מובייל.

## פרטיות ואבטחה

* **אין שרת אחורי ואין בסיס נתונים.** הדפדפן מדבר ישירות עם ספקי הנתונים.
* **היחיד שרץ מקומית הוא שרת הקבצים** ובתוכו proxy צר ל־Yahoo: רק GET, רק שני הנתיבים
  שהאפליקציה משתמשת בהם, רק אל `query1.finance.yahoo.com`, והאזנה על 127.0.0.1 בלבד.
* **רשימת היתר לכתובות** — האפליקציה יכולה לפנות רק למארחים המוגדרים ב־`src/lib/config.js`.
  הבדיקה `npm run build` נכשלת אם קוד כלשהו פונה למארח אחר.
* **נתוני ספקים נחשבים קלט לא מהימן** — שמות וסמלים מוצגים תמיד כטקסט (`textContent`),
  לעולם לא כ־HTML. ייצוא CSV מנוטרל מפני הזרקת נוסחאות.
* **מה נשמר בדפדפן:** כללי התראות, היסטוריית התראות, רשימת המעקב, העדפות ומפתח Finnhub —
  ב־localStorage בלבד. למחיקה מלאה: **הגדרות** ← **מחיקת כל הנתונים השמורים**.
* **אין מדידות, טלמטריה או משאבים חיצוניים** — אין גופנים מרוחקים, אין CDN, אין סקריפטים של
  צד שלישי.

## מגבלות ידועות

* **לא נבדק מול נקודות הקצה החיות.** הקוד נכתב לפי הפורמטים המתועדים של הספקים ונבדק מול
  שרת דמה שמדבר באותם פורמטים; סביבת הפיתוח שבה נכתב חסמה גישה לרשת אל Binance, Yahoo,
  Finnhub ו־CoinGecko. ההרצה הראשונה מול הספקים האמיתיים היא אצלך.
* **נתוני Yahoo אינם מובטחים כזמן אמת** ומסומנים «ייתכן עיכוב». לזמן אמת במניות — Finnhub.
* **מגבלות שימוש בשכבה החינמית:** CoinGecko מגביל לכמה עשרות קריאות בדקה, ו־Finnhub מגביל
  מנויים בשכבה החינמית. סקר תכוף מדי יביא לשגיאות 429.
* **אין מצב בהיר.** העיצוב כהה בלבד; גרסה בהירה דורשת סט החלטות משלה ולא היפוך טוקנים.
* **אין לוח שנה של שעות מסחר.** מחוץ לשעות המסחר מניות פשוט מפסיקות להתעדכן, והכלי מציג
  «עודכן לפני…» במקום לטעון שהשוק סגור.
* **ההתראות פועלות רק כשהדף פתוח.** אין Service Worker, אין התראות כשהדפדפן סגור.
* **היסטוריית הגרף מוגבלת** ל־240 נרות של דקה (כ־4 שעות) לכל נכס, כדי שלשונית שנשארת פתוחה
  כל היום לא תצבור זיכרון.
* **מחזור במניות דרך Finnhub** אינו זמין בנקודת הקצה `/quote` בשכבה החינמית; מוצג המחזור
  שנצפה מאז פתיחת הדף.
* **אין אימות צולב בין ספקים.** מה שהספק שלח הוא מה שמוצג.
* זהו כלי מעקב ותצוגה. אין בו ייעוץ, אין בו המלצות, ואין בו ביצוע פקודות.

## פתרון תקלות

| תופעה | סיבה ופתרון |
|---|---|
| הדף ריק, בקונסול `CORS policy` | נפתח `index.html` ישירות מהדיסק. יש להריץ `npm start` ולגשת ל־`http://127.0.0.1:4173/`. |
| «קריפטו — מתחבר מחדש…» שוב ושוב | Binance חוסם את האזור שלך, או אין חיבור. לנסות את נקודת הקצה של binance.us (ראו למעלה). |
| «מניות — שגיאה» עם 502 או 504 | ה־proxy לא הצליח להגיע ל־Yahoo. לבדוק חיבור לאינטרנט; אם יש חומת אש, להשתמש ב־Finnhub. |
| «מניות — שגיאה: Invalid token» | מפתח Finnhub שגוי או פג. לבדוק בלוח הבקרה של finnhub.io או למחוק את המפתח ולחזור ל־Yahoo. |
| מחירי מניות לא זזים | ייתכן שהשוק סגור. יש לבדוק את שעת «עדכון אחרון» בכרטיס. |
| «מחובר · אין עדכונים» | החיבור פתוח אבל הערוץ שקט יותר מדקה. בדרך כלל: שוק סגור או צמד לא נזיל. |
| כפתור ההתראות כתוב «התראות חסומות» | ההרשאה נדחתה בעבר. יש ללחוץ על סמל המנעול בשורת הכתובת ולאפשר «התראות», ואז לרענן. |
| התראות לא מופיעות כשהלשונית ברקע | לבדוק שההרשאה ניתנה, ושמצב «נא לא להפריע» של מערכת ההפעלה כבוי. |
| אין צליל בהתראה | הדפדפן חוסם שמע עד לאינטראקציה. יש ללחוץ פעם אחת על הדף (למשל «הפעלת התראות») ולוודא ש«צליל פעיל». |
| התראה לא נורתה למרות שהתנאי התקיים | ייתכן שהכלל עדיין נעול מהפעלה קודמת («ממתינה לאיפוס התנאי») או בתוך זמן צינון. |
| כלל מסומן «אין מספיק היסטוריה» | חלון הזמן ארוך מכמות הנתונים שנאספה מאז פתיחת הדף. להמתין או לקצר את החלון. |
| שגיאות 429 | סקר תכוף מדי מול השכבה החינמית. להגדיל את `stockPollMs` או להמתין דקה. |
| `Error: listen EADDRINUSE` | הפורט תפוס: `npm start -- --port 8080`. |
| `npm run test:e2e` מדלג | Playwright אינו מותקן. זו בדיקה אופציונלית; `npm test` היא הבדיקה העיקרית. |

### הרחבה בספק נוסף

כל ספק מייצא פונקציות פענוח **טהורות** שמקבלות מטען גולמי ומחזירות את המודל המנורמל
(`Quote` / `Candle` / `Trade`). להוספת ספק: לכתוב מודול כזה, להוסיף את המארח לרשימת ההיתר
ב־`src/lib/config.js` וב־`scripts/audit.mjs`, ולחבר אותו ב־`src/main.js`. שאר האפליקציה —
הגרפים, הסטטיסטיקה ומנוע ההתראות — אינה יודעת מאיזה ספק הגיע המספר.
