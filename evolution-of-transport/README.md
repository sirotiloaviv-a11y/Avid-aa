# התפתחות התחבורה: מגלגל אבן לחללית

סרטון קולנועי של 25 שניות, אנכי 1080×1920 ב-30fps, ללא טקסט על המסך.
הפרויקט כולל שני חלקים:

1. **`shots/SHOTS.md`**: תנ״ך השוטים. חוקי רציפות (כיוון, עוגנים, עדשה, תאורה ופלטת צבעים)
   ופרומפטים באנגלית ל-8 פריימי מפתח (K0–K7) ול-7 שוטים (S1–S7).
2. **פרויקט עריכה ב-Remotion**: קולט את הקטעים שנוצרו, מתאים את האורך של כל קטע לסלוט שלו,
   חותך במדויק על פריימים זהים, משלב מוזיקה ו-15 אפקטים קוליים ומרנדר MP4 בקידוד H.264.

## מה חסר כדי להפיק את הסרטון

| חסר | למה | מה עושים |
| --- | --- | --- |
| 7 קטעי וידאו פוטוריאליסטיים (`public/clips/S1–S7.mp4`) | אין בסביבה הזו כלי ליצירת וידאו או תמונות, וה-APIs של שירותי היצירה חסומים ברשת | מייצרים לפי `shots/SHOTS.md` בכלי שתומך בפריים התחלה ופריים סיום |
| 8 פריימי מפתח (`public/keyframes/K0–K7.png`) | אותה סיבה | מייצרים במודל תמונה לפי סעיף 3 ב-SHOTS.md |
| מוזיקה ואפקטים (`public/audio/…`) | אין נכסים עם רישיון מתאים, ואין גישה להורדה | קבצים ברישיון מתאים לפי סעיף 5; קובץ חסר פשוט מדולג |
| סרטון הרפרנס | לא הגיע לסשן | להוסיף אותו לריפו, והשוטים יותאמו אליו |

## הרצה

```bash
cd evolution-of-transport
npm install
npm run check    # בודק שכל הקטעים קיימים ובמפרט (אורך, יחס 9:16, fps)
npm run stills   # פריים מאמצע כל שוט ו-3 פריימים סביב כל חיתוך, ל-out/review/
npm run render   # רינדור הסרטון המלא
```

פקודת הרינדור המלאה (`npm run render` מריץ קודם את הבדיקה):

```bash
npx remotion render src/index.ts Evolution out/evolution-of-transport.mp4 --codec=h264 --crf=16 --audio-codec=aac
```

הרינדור לא מתחיל כל עוד חסר קטע כלשהו, כך שלא ייצא קובץ עם חורים.

## מבנה

```
shots/manifest.json   תזמון, קבצים, התאמת אורך ורמזי סאונד (מקור אמת אחד)
shots/SHOTS.md        תנ״ך השוטים והפרומפטים
src/shots.ts          בונה את ציר הזמן מה-manifest (750 פריימים)
src/Evolution.tsx     הקומפוזיציה: שוטים ברצף ופס קול
src/components/ShotClip.tsx   קטע אחד, מותאם לסלוט שלו (trim ומהירות)
src/components/Soundtrack.tsx מוזיקה עם fade ואפקטים לפי זמן
scripts/check-assets.mjs      בדיקה לפני רינדור
scripts/render-review-stills.mjs  ייצוא פריימים לבדיקה
```

## כוונון

- **שינוי אורך או תזמון:** `startSec`/`endSec` ב-`manifest.json`.
- **קטע שנוצר באורך אחר:** מעדכנים `sourceSec`. הקטע יואץ או יואט אוטומטית, בטווח 0.75–1.33×.
- **הפרש צבע קטן בנקודת חיבור:** `seamFrames` ל-2–3. ברירת המחדל 0, כלומר חיתוך נקי.
