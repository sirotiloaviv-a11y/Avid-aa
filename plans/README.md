# plans/

Standalone personal pages. Not part of `moat/` or `security_alert_system/` —
each file here is a self-contained HTML page with no build step and no
dependencies, meant to be opened directly in a browser.

- [`weekly-workout-nutrition-plan.html`](weekly-workout-nutrition-plan.html) —
  תוכנית שבועית של אימונים ותזונה. Hebrew (RTL), bodyweight-only training week
  plus daily nutrition, with a pull-up progression tracker. Collapsible day
  cards; prints with every day expanded.
