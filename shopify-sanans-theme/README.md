# סנאנס — ערכת עיצוב לסופרמרקט אונליין (Shopify · Dawn)

סקשנים, סניפטים ו-CSS מותאמים לתבנית **Dawn** (Online Store 2.0), בעברית ובכיוון RTL.

```
shopify-sanans-theme/
├── assets/
│   ├── sanans-grocery.css          ← כל העיצוב (טוקנים, כרטיסים, תגיות, כפתורים, התאמות ל-Dawn)
│   └── sanans-quick-add.js         ← הוספה מהירה לעגלה ב-AJAX (פותח את מגירת העגלה)
├── sections/
│   ├── sanans-hero.liquid          ← Hero עם חיפוש בולט ו-CTA
│   ├── sanans-categories.liquid    ← קטגוריות בעיגולים
│   ├── sanans-deals.liquid         ← דיל יומי עם שעון ספירה לאחור + שורת מוצרים
│   ├── sanans-featured-products.liquid ← גריד מוצרים מומלצים
│   └── sanans-trust.liquid         ← יתרונות ואמון
├── snippets/
│   ├── sanans-product-card.liquid  ← כרטיס מוצר + הוספה מהירה
│   └── sanans-sale-badge.liquid    ← תגיות מבצע / 1+1 / חדש / אזל
├── layout/theme-liquid-additions.liquid ← 3 תוספות ל-theme.liquid
└── brand/                           ← הלוגו ותמונות המוצרים
```

---

## 1. מיתוג

**ניתוח:** הלוגו בכחול נייבי עמוק, אותיות עבות ומעוגלות, עגלה וקו "חיוך" — מסר של אמינות וסולידיות.
תמונות המוצרים (סוגת, תנובה, השחר) צבעוניות וחזקות — לכן הממשק צריך להיות **נקי ובהיר** כדי שהאריזות יבלטו,
עם צבע הנעה לפעולה אחד שלא מתחרה בהן.

| תפקיד | HEX | שימוש |
|---|---|---|
| נייבי מותג | `#12295E` | כותרות, מחירים, כותרת עליונה, פוטר |
| נייבי כהה | `#0B1D45` | hover, רקע Hero |
| **ירוק "הוסף לעגלה"** | `#0B8043` | כל כפתורי הקנייה (ניגודיות 5:1 עם לבן — עומד ב-WCAG AA) |
| ירוק hover | `#086634` | |
| ירוק בהיר (אייקונים) | `#22C55E` | וי, נקודות "פתוח" |
| **אדום מבצע** | `#D91E2A` | תגיות הנחה ומחיר מבצע בלבד |
| צהוב דילים | `#FFC72C` | באנר דיל יומי, מדבקות, focus |
| רקע | `#FFFFFF` | |
| משטח | `#F6F8FB` | רקע תמונות מוצר, כרטיסי אמון |
| גבול | `#E5E9F0` | |
| טקסט | `#152036` | |
| טקסט משני | `#5E6A7E` | מותג, מחיר ליחידה, מחיר מקורי |

כלל אצבע: **ירוק = קונים, אדום = חוסכים, נייבי = סומכים.** לא להשתמש באדום לשום דבר חוץ ממבצעים.

**פונטים (Google Fonts):**
- **Heebo** — גוף, כפתורים ומחירים. קריא מאוד במסכים קטנים, ספרות ברורות.
- **Rubik** — כותרות. עגול ועבה, מהדהד את אותיות הלוגו.
- חלופה: **Assistant** לגוף אם רוצים מראה קליל יותר.

## 2. מבנה עמוד הבית

1. **כותרת עליונה (Dawn)** — לוגו, חיפוש, חשבון, עגלה. פס הודעה מעל: "משלוח חינם בהזמנה מעל ₪250 🚚".
2. **Hero** — כותרת + שורת חיפוש ענקית + CTA ירוק + 3 נקודות אמון קצרות.
3. **קטגוריות מהירות** — 8 עיגולים: מזווה · חלב וביצים · ממרחים ומתוקים · פירות וירקות · לחם ומאפים · משקאות · חירום ומוצרי יסוד · ניקיון ובית. נגלל אופקית במובייל.
4. **דיל יומי** — באנר צהוב עם שעון עד חצות + שורת מוצרים במבצע.
5. **הכי נמכרים השבוע** — גריד מוצרים עם הוספה מהירה.
6. **(אופציונלי) קולקציה נוספת** — "מוצרי יסוד לבית" או "מלאי חירום", אותו סקשן עם קולקציה אחרת.
7. **אמון ויתרונות** — משלוח · טריות · החזר כספי · שירות.
8. **פוטר (Dawn)** — שעות פעילות, אזורי משלוח, וואטסאפ, תקנון ונגישות.

העיקרון: המשתמש צריך להגיע למוצר ב-**קליק אחד** (חיפוש / קטגוריה) ולהוסיף לעגלה ב-**קליק אחד** נוסף, בלי לעזוב את העמוד.

## 3. התקנה — צעד אחר צעד

> לפני הכל: **Online Store → Themes → ⋯ ליד Dawn → Duplicate**. עבדו על העותק, ופרסמו רק כשהכל נראה טוב.

פתחו את העורך: **Online Store → Themes → ⋯ → Edit code**.

### שלב א' — קבצי Assets
1. בתיקייה **assets** לחצו **Add a new asset → Create a blank file**.
2. צרו `sanans-grocery.css` והדביקו את תוכן [`assets/sanans-grocery.css`](assets/sanans-grocery.css).
3. צרו `sanans-quick-add.js` והדביקו את תוכן [`assets/sanans-quick-add.js`](assets/sanans-quick-add.js).

### שלב ב' — Snippets
בתיקייה **snippets** → **Add a new snippet**:
1. `sanans-sale-badge` ← [`snippets/sanans-sale-badge.liquid`](snippets/sanans-sale-badge.liquid)
2. `sanans-product-card` ← [`snippets/sanans-product-card.liquid`](snippets/sanans-product-card.liquid)

### שלב ג' — Sections
בתיקייה **sections** → **Add a new section**, צרו כל אחד מהם (השם בלי `.liquid`), מחקו את תוכן ברירת המחדל והדביקו:
`sanans-hero`, `sanans-categories`, `sanans-deals`, `sanans-featured-products`, `sanans-trust`.

### שלב ד' — theme.liquid
פתחו **layout/theme.liquid** ובצעו את שלוש התוספות מ-[`layout/theme-liquid-additions.liquid`](layout/theme-liquid-additions.liquid):
1. הוסיפו `dir="rtl"` לשורת `<html ...>`.
2. לפני `</head>` — הפונטים וה-CSS.
3. לפני `</body>` — ה-JS.

שמרו (**Save**).

### שלב ה' — הגדרות ערכת הנושא
**Customize → Theme settings**:
- **Cart → Cart type: Drawer** — ההוספה המהירה תפתח את מגירת העגלה.
- **Logo** — העלו את הלוגו, רוחב ~160px.
- **Colors** — ב-Scheme 1 רקע `#FFFFFF`, טקסט `#152036`, כפתור `#0B8043`.

### שלב ו' — בניית עמוד הבית
**Customize → Home page**: מחקו/הסתירו את סקשני ברירת המחדל, ואז **Add section** לפי הסדר:
Hero → קטגוריות → דיל יומי → מוצרים מומלצים → אמון ויתרונות.
בכל סקשן בחרו קולקציה ותמונות, ובקטגוריות — קשרו כל עיגול לקולקציה.

### שלב ז' — הכנת המוצרים
- **Compare at price** גבוה מהמחיר → תגית הנחה באחוזים מופיעה אוטומטית.
- Tag בפורמט `badge:1+1` או `badge:2 ב-₪20` → תגית צהובה עם הטקסט.
- Tag `חדש` → תגית ירוקה "חדש".
- **Vendor** = שם המותג (תנובה, סוגת, השחר) → מוצג מעל שם המוצר.
- **Unit price** (במוצר → Pricing → Show unit price) → "₪X ל-100 גרם" מתחת למחיר.
- תמונות: רקע לבן או שקוף, ריבועיות. הכרטיס "מעלים" רקע לבן אוטומטית.

### (אופציונלי) אותו כרטיס בעמודי קטגוריה
ה-CSS כבר מעצב את כרטיסי Dawn המקוריים. אם רוצים את הכרטיס המלא עם כמות +/−, ב-**sections/main-collection-product-grid.liquid** החליפו:
```liquid
{% render 'card-product', card_product: product, ... %}
```
ב:
```liquid
{% render 'sanans-product-card', product: product %}
```

## 4. מיקרו-קופי

**כותרות Hero:**
- "כל המצרכים שאתם צריכים, **עד הדלת תוך שעות**"
- "הסופר של השכונה. **עכשיו גם בלחיצה.**"
- "מזמינים בבוקר, **מבשלים בערב**"
- "העגלה מתמלאת, **הזמן שלכם נשאר פנוי**"

**באנרים:**
- דיל יומי: "מחירים שלא חוזרים — רק עד חצות"
- מוצרי יסוד: "המזווה מלא, הראש שקט"
- חלב וביצים: "טרי מהקירור — לא מהמחסן"
- חירום: "מלאי חירום לבית, מוכן במשלוח אחד"
- משלוח חינם: "משלוח חינם בהזמנה מעל ₪250 🚚"

**אמון:**
- **משלוח עד הבית, עוד היום** — מזמינים עד 14:00, מקבלים עוד היום.
- **טריות מובטחת** — מוצרים טריים נאספים רק לפני היציאה אליכם, בשרשרת קירור מלאה.
- **לא מרוצים? מחזירים כסף** — מוצר לא הגיע כמו שציפיתם? זיכוי מלא, בלי שאלות.
- **אנשים אמיתיים בשירות** — צוות מהשכונה בוואטסאפ ובטלפון.
- **תשלום מאובטח** — כל התשלומים מוצפנים. אפשר גם ביט ו-Apple Pay.

**כפתורים ומצבים:** "הוספה" → "נוסף ✓" · "בחירת גודל / סוג" · "אזל זמנית" · "להתחיל לקנות" · "לכל הדילים"

**חיפוש:** "מה חסר לכם היום? חלב, ביצים, אורז…"
**עגלה ריקה:** "העגלה עדיין ריקה — בואו נמלא אותה 🛒"
