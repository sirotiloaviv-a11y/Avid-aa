# מרכז מידע שוק — אבטיפוס מקומי

כלי מידע ומחקר על מניות וקריפטו, עם שני מצבים:

- **הדגמה** (ברירת המחדל) — כל הנכסים, המחירים, הידיעות והאירועים בדיוניים. עובד בלי שום הגדרה.
- **נתוני שוק** — מחירים והיסטוריית מחירים ממקורות אמיתיים, **מושהים או סוף יום, לא בזמן אמת**.
  ליד כל נתון מוצגים המקור, מועד הנתון וסוג ההשהיה. חדשות, אירועים והתראות מוצגים כ„טרם חובר”.

המערכת אינה מחוברת לחשבון מסחר, אינה מבצעת עסקאות ואינה נותנת המלצות קנייה או מכירה.

## הפעלה

צריך רק [Node.js](https://nodejs.org) (גרסה 18 ומעלה). אין חבילות להתקנה.

- **Windows:** לחיצה כפולה על `start-windows.bat`
- **Mac:** לחיצה כפולה על `start-mac.command` (בפעם הראשונה: קליק ימני ← „פתח”)
- **מכל מערכת, בטרמינל, מתוך התיקייה `market_info`:** `npm start`

אחר כך פותחים בדפדפן: **http://localhost:5173**. לעצירה: `Ctrl+C` בחלון הטרמינל.

השרת מאזין רק למחשב המקומי (`127.0.0.1`) ואינו נגיש מבחוץ.

## הפעלת מצב נתוני שוק (פעם אחת)

1. בתיקייה `market_info` צרו עותק של הקובץ `.env.example` וקראו לו `.env`.
2. הירשמו **בעצמכם** לקבלת מפתחות חינמיים:
   - מניות — Alpha Vantage: https://www.alphavantage.co/support/#api-key
   - קריפטו — CoinGecko, מסלול Demo: דרך חשבון מפתחים באתר coingecko.com
3. פתחו את `.env` בעורך טקסט והדביקו את המפתחות אחרי סימן השוויון:
   ```
   ALPHA_VANTAGE_API_KEY=your-key
   COINGECKO_DEMO_API_KEY=your-key
   ```
4. הפעילו מחדש את השרת. בחלון השרת תופיע השורה „מפתח ... הוגדר”.
5. במערכת: הגדרות ← מצב נתונים ← „נתוני שוק” ← שמירה.

אפשר להגדיר רק ספק אחד; החלק שאין לו מפתח יוצג כ„נדרשת הגדרה”.
**אל תדביקו מפתחות בצ׳אט, בקוד או ב-Git.** הקובץ `.env` מוחרג מ-Git, והמפתחות נקראים רק בשרת המקומי ולא נשלחים לדפדפן.

## מקורות הנתונים

| | מניות — Alpha Vantage | קריפטו — CoinGecko (Demo) |
|---|---|---|
| מה נלקח | `TIME_SERIES_DAILY` (‏100 ימי מסחר אחרונים) | `/coins/markets`, `/coins/{id}/market_chart` (‏90 יום) |
| סוג הנתון | **סוף יום** — מחירי סגירה יומיים | **מושהה** — הספק מעדכן בדרך כלל כל כמה דקות |
| מגבלות במסלול החינמי* | כ-25 בקשות ביום, כ-5 בדקה | 30 בקשות בדקה (יש מקורות שמציינים 100), 10,000 בחודש |
| עלות | חינם; זמן אמת רק במסלולים בתשלום | חינם; עדכון תכוף יותר במסלולים בתשלום |
| תנאים | תנאי השימוש של Alpha Vantage | חובה להציג „Powered by CoinGecko” (מוצג במערכת) |
| חסר במקור | — | אין נרות (פתיחה/גבוה/נמוך); הנפח הוא נפח 24 שעות בדולרים |

\* **הסתייגות:** בזמן הפיתוח אתרי הספקים היו חסומים מסביבת העבודה, ולכן לא נקראו דפי התיעוד הרשמיים עצמם.
הנתונים בטבלה נאספו מתוצאות חיפוש, חלקן מתוך אתרי הספקים. בדקו את דפי התמחור והתנאים העדכניים לפני שימוש.
המכסות ניתנות לשינוי בקובץ `.env`.

### אמינות

- **מטמון:** מניות 6 שעות, מחירי קריפטו 2 דקות, היסטוריית קריפטו שעה. המטמון נשמר בדיסק (`.cache/`, מוחרג מ-Git), כך שהפעלה מחדש לא צורכת בקשות.
- **מכסה מקומית:** המערכת סופרת בקשות ועוצרת לפני מכסת הספק. כשהספק מחזיר 429, הבקשות נעצרות לפי `Retry-After`.
- **נתון ישן:** כשהספק נכשל וקיים עותק קודם, מוצג העותק עם סימון „נתון ישן — העדכון האחרון נכשל” וזמן העדכון האחרון.
  אם אין עותק, מוצגת שגיאה. נתוני הדגמה **לעולם** אינם משמשים כתחליף.
- **שוק סגור ≠ תקלה:** מצב המסחר בארה״ב מחושב לפי שעות מסחר רגילות בניו יורק (ללא חגים). כשהשוק סגור מוצג מחיר הסגירה האחרון כרגיל; תקלה מוצגת בנפרד.
- **סימול לא תקין:** סימול בפורמט שגוי לא נשלח לספק; סימול שהספק לא מכיר מוצג כ„נכס לא נמצא”.
- **נתונים חסרים:** שורות פגומות מושמטות; נפח או נרות שחסרים במקור לא מושלמים.

## פקודות

| פקודה | מה היא עושה |
|---|---|
| `npm start` | מריץ את המערכת מתוך `src/` |
| `npm run build` | בדיקת בנייה: תחביר, ייבואים, חיפוש מפתחות סודיים, העתקה ל-`dist/` |
| `npm run preview` | מריץ את הגרסה הבנויה מתוך `dist/` |
| `npm test` | בדיקות יחידה (נתונים, סינון, אחסון, תאריכים) |
| `npm run e2e` | בדיקות בדפדפן אמיתי. דורש Playwright מותקן בנפרד; אם אינו מותקן — מדלג. מצב נתוני שוק נבדק מול ספק מדומה, לא מול הספקים האמיתיים |

## מבנה

```
server.mjs                ← שרת מקומי: קבצים סטטיים + ‎/api/market/*
server/
  config.mjs              ← קריאת ‎.env (מפתחות, נכסים, מכסות)
  marketService.mjs       ← איחוד ספקים, מטמון, מכסות, סימון מקור/זמן/השהיה
  cache.mjs, budget.mjs   ← מטמון בדיסק ומונה בקשות
  time.mjs                ← שעות מסחר בניו יורק, זיהוי נתון ישן
  providers/              ← Alpha Vantage, CoinGecko (מיפוי תשובות וסיווג שגיאות)
src/
  index.html, styles.css
  js/
    data/provider.js      ← החוזה שהמסכים תלויים בו (נקודת החיבור למקור אמיתי)
    data/demoProvider.js  ← מימוש הדגמה: השהיה מדומה, שגיאה מדומה
    data/marketProvider.js← מצב נתוני שוק: פונה רק לשרת המקומי
    data/demoData.js      ← נתוני הדגמה עקביים (זרע קבוע)
    data/filters.js       ← חיפוש וסינון
    store.js              ← העדפות, רשימת מעקב, תזכורות — localStorage בלבד
    views/                ← המסכים
    ui/                   ← גרף ורכיבים משותפים
```

## הוספת ספק נתונים נוסף

1. בשרת: מודול חדש ב-`server/providers/` שממפה את תשובות הספק לפורמט הנורמלי (`bars`, מחיר, `asOf`) ומסווג שגיאות ל-`MarketError`.
2. חיבור שלו ב-`server/marketService.mjs`, עם מטמון ומכסה משלו ותיאור השהיה מדויק.
3. בדפדפן אין מה לשנות: המסכים מקבלים את הנתונים דרך `MarketProvider`.

מפתחות נקראים רק בשרת, מ-`.env` או ממשתני סביבה.
